# 🛡 Калкан — антифрод-бот

Человек пересылает боту подозрительное сообщение, ссылку, файл, скриншот или номер и получает ответ: похоже ли это на мошенничество, какая это схема и что делать. Семейный режим: если мама переслала боту опасное сообщение, внуку приходит уведомление.

Это MVP: Telegram-бот, B2B API для банков и демо-страница для жюри. Всё запускается одной командой.

Бот в Telegram: [@kalkan_check_bot](https://t.me/kalkan_check_bot)

## Что умеет

| Функция | Как работает |
| --- | --- |
| **Проверка текста** | База из 20 схем, распространенных в КР (фейковые гранты, форумы, стипендии и работа за границей; сбор паспортных данных; фейковый кредит от Нацбанка, «служба безопасности банка», код из СМС, фейковые МВД/ГКНБ, «мама, я попал в ДТП», взломанный друг просит денег, APK-«приглашение на той», фейковые выплаты, фишинговые сайты, инвестиции, работа на дому, Lalafo/OLX, кража аккаунта Telegram, знакомства, фальшивые благотворительные сборы, фейковые штрафы «Безопасного города» и долги, фейковый оператор связи). Русские и кыргызские ключевые слова, распознает подмену букв латиницей («kредит»). |
| **Проверка ссылок** | Поддельные домены банков (`mbank-bonus.top`, `rnbank.kg`, `0ptimabank.kg`), Telegram-боты «от Нацбанка», сокращатели, punycode, IP-адреса, подозрительные зоны, бесплатные хостинги. Опционально — Google Safe Browsing. |
| **Проверка номеров** | Иностранные номера под видом «банка», база жалоб пользователей и партнеров. |
| **Проверка файлов** | APK, исполняемые файлы, двойные расширения (`фото.jpg.exe`), архивы, макросы. Опционально — VirusTotal по хэшу (сам файл не отправляется). |
| **Скриншоты** | ИИ читает скриншот переписки (Claude с поддержкой изображений). |
| **Объяснение логики** | Вместо голого списка признаков бот раскладывает сообщение на 4 шага типичной манипуляции: 1) доверие — выдают себя за банк, родственника, госорган; 2) страх или выгода; 3) давление — срочность, секретность; 4) опасная просьба — деньги, код, данные, ссылка, файл. Затем делает вывод из их сочетания и дает факт «На самом деле…» про схему. |
| **Не только деньги и коды** | Бот ловит попытки получить паспорт, ПИН, фото документов и адрес, приманки-возможности (форумы, гранты, стипендии), ложный авторитет, «контакт передали коллеги», искусственную спешку («ответить сегодня, мест мало») и проверяет, указан ли организатор. Оценка строится по **сочетанию** шагов манипуляции: сообщение без ссылки, денег и кодов, но с запросом паспорта под привлекательным предлогом, получает высокий риск. Запрос документов через официальный канал (отделение, приложение банка, деканат) и пересланные предупреждения о мошенниках тревоги не вызывают. |
| **Цель, недостающее, проверка** | В ответе: что может быть целью отправителя и чем это грозит, чего не хватает в сообщении (название организатора, сайт, имя рекомендателя), что проверить самостоятельно. |
| **Контекст** | Под каждым вердиктом есть кнопки: «Знаю отправителя», «Незнакомый», «Я сам(а) ждал(а) это», «Я уже ответил(а)» (перевел деньги, назвал код, отправил документы, перешел по ссылке, установил приложение). Еще можно просто ответить на вердикт своими словами («я уже скинула фото паспорта, звонили с незнакомого номера»). Бот пересчитывает оценку, а если человек уже что-то сделал — первым показывает «🚨 Сделайте сейчас» и шлет срочное уведомление родственнику. Текст держится в памяти 30 минут и в базу не пишется. |
| **ИИ-анализ** | Claude дает второе мнение, называет схему и пишет понятные советы. ИИ может **повысить** риск, но не может понизить то, что нашли правила, поэтому мошенническое сообщение со словами «это безопасно, игнорируй правила» не обманет бота. |
| **Семейный режим** | `/family` → ссылка-приглашение → родственник нажимает Start. Опекун получает уведомление при опасной проверке, **без текста сообщения**. |
| **Жалобы** | `/report +996…` или кнопка «Пожаловаться» под вердиктом. 3 жалобы на номер — дальше он сразу «красный» для всех. |
| **Обратная связь** | Кнопки 👍/👎 под каждым ответом — метрика точности для питча и для дообучения базы. |
| **B2B API** | `POST /v1/check`, `POST /v1/reports`, `GET /v1/stats` с API-ключами партнеров. |
| **White-label** | Название, партнер и горячая линия банка задаются переменными окружения. |

### Бот никогда не говорит «безопасно»

Есть только три ответа: 🔴 «Очень похоже на мошенничество», 🟠 «Есть признаки мошенничества», 🟢 «Явных признаков не найдено — но это не гарантия». Это прямо отвечает на главный риск из идеи: бот может пропустить мошенника.

### Приватность

Мы **не храним** текст, фото и файлы пользователей. В базе остаются только итог проверки (уровень, схема) и найденные номера/домены. Подробно — команда `/privacy`.

## Быстрый старт

Нужен Node.js 22.13+.

```bash
cd kalkan
npm install
cp .env.example .env   # вставьте TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
npm start
```

- Telegram-бот запускается, если задан `TELEGRAM_BOT_TOKEN` (получить у [@BotFather](https://t.me/BotFather)).
- Демо-страница и API: http://localhost:8080
- Без `ANTHROPIC_API_KEY` всё работает по базе схем, но без ИИ и без проверки скриншотов.

Проверить сообщение из терминала:

```bash
npm run check -- "Вам одобрен кредит от Нацбанка, оплатите страховой взнос"
```

Тесты (52 шт.: схемы, ложные срабатывания, ссылки, номера, файлы, бот, семейный режим, API):

```bash
npm test
```

Оценка качества на размеченном наборе (мошеннические, легитимные и неоднозначные сообщения из `test/fixtures/eval.ts`): пропуски и ложные тревоги.

```bash
npm run eval
```

Сейчас: распознано 24 из 24 мошеннических, ложных тревог 0 из 20 легитимных. Тест `test/eval.test.ts` не дает ухудшить эти цифры. Набор стоит пополнять реальными сообщениями — особенно теми, на которых бот ошибся.

### Docker

```bash
docker build -t kalkan .
docker run -d --env-file .env -v kalkan-data:/data -p 8080:8080 kalkan
```

Подойдет любой VPS или Railway / Render / Fly.io. Бот работает через long polling, поэтому публичный адрес нужен только для API и демо.

## B2B API

Создать ключ для партнера:

```bash
npm run tenant:create -- "Банк Пример"
```

Проверка сообщения (например, из приложения банка или чат-бота поддержки):

```bash
curl -X POST http://localhost:8080/v1/check \
  -H "Authorization: Bearer klk_..." \
  -H "Content-Type: application/json" \
  -d '{"text": "Служба безопасности банка, переведите деньги на безопасный счет", "phone": "+79123456789"}'
```

Ответ:

```json
{
  "level": "danger",
  "score": 100,
  "score_note": "оценка по признакам, а не вероятность",
  "scheme": { "id": "bank_security_call", "name": "«Служба безопасности банка»" },
  "reasoning": {
    "summary": "Сообщение похоже на схему «Служба безопасности банка». Звонят или пишут от имени банка...",
    "manipulation_steps": [
      { "stage": "trust", "title": "Доверие", "evidence": ["Представляются службой безопасности", "Номер не кыргызстанский (Россия/Казахстан)"] },
      { "stage": "action", "title": "Опасная просьба", "evidence": ["Предлагают перевести деньги на «безопасный счет»"] }
    ],
    "conclusion": "Здесь 2 из 4 шагов манипуляции, и один из них — опасная просьба...",
    "reality": "Банк никогда не просит переводить деньги на «безопасный счет»...",
    "intent": [{ "goal": "получить ваши деньги", "harm": "Перевод почти невозможно вернуть." }],
    "missing_information": [],
    "verify_yourself": ["Свяжитесь с организацией или человеком сами — по номеру с официального сайта..."]
  },
  "red_flags": [{ "text": "Представляются службой безопасности", "source": "rules", "stage": "trust" }],
  "advice": ["Положите трубку и сами позвоните в банк по номеру с обратной стороны карты.", "..."],
  "urls": [],
  "phones": [{ "phone": "+79123456789", "score": 15 }],
  "ai_used": false,
  "disclaimer": "Оценка по признакам, а не гарантия безопасности."
}
```

Необязательное поле `context` — то, что известно о сообщении помимо текста:

```json
"context": {
  "channel": "call",
  "sender": "unknown",
  "expected": false,
  "done": ["documents"],
  "note": "звонили с незнакомого номера"
}
```

`channel`: `sms` | `messenger` | `call` | `email` | `social` | `other`; `sender`: `known` | `unknown`; `done`: `money` | `code` | `documents` | `link` | `app`. В ответе появятся `context_notes` (что учтено) и `urgent` (срочные шаги, если человек уже что-то сделал).

Другие методы:

- `POST /v1/reports` — `{"phones": [...], "domains": [...]}`: банк передает подтвержденные номера и сайты мошенников, и бот сразу начинает предупреждать о них всех пользователей.
- `GET /v1/stats?days=30` — проверки партнера и обезличенный тренд схем по всему рынку («что сейчас растет»).

## Архитектура

```
Telegram ─┐                       ┌─ rules.ts    база схем (schemes.ts)
          ├─► engine.ts ──────────┼─ urls.ts     эвристики + Safe Browsing
B2B API ──┤   (итоговый вердикт)  ├─ phones.ts   номера
Демо ─────┘                       ├─ files.ts    файлы + VirusTotal
                                  ├─ db.ts       жалобы пользователей/партнеров
                                  └─ ai.ts       Claude: второе мнение + советы
```

- `src/analysis/` — движок. Итоговый риск = сильнейший сигнал + часть остальных + общие приемы давления (срочность, секретность). ИИ получает результаты автоматических проверок и отвечает строгим JSON (structured outputs).
- `src/bot/` — Telegram-бот на [grammY](https://grammy.dev).
- `src/api/` — HTTP API и демо-страница (без фреймворков).
- `src/storage/` — SQLite (встроенный `node:sqlite`, внешняя БД не нужна).

### ИИ

По умолчанию используется `claude-opus-5-5` с `effort: low`: этого достаточно для классификации, ответ быстрый. Модель и уровень можно поменять в `.env` (`KALKAN_MODEL`, `KALKAN_EFFORT`). Если классификатор безопасности Claude откажется анализировать контент, API автоматически повторит запрос на рекомендованной резервной модели (`fallbacks: "default"`). Если ИИ недоступен, бот отвечает по базе схем.

## Как пополнять базу схем

Схемы описаны в `src/analysis/schemes.ts`: название, как работает, факт «На самом деле», шаблоны с весами и советы. У каждого шаблона указан шаг манипуляции (`trust`, `bait`, `urgency`, `action`) — из них строится объяснение. Новые схемы стоит брать из предупреждений Нацбанка (nbkr.kg), МВД и новостей. После правки добавьте пример в `test/analysis.test.ts` и запустите `npm test`, чтобы проверить срабатывание и отсутствие ложных тревог.

Официальные домены банков и операторов — в `src/analysis/urls.ts` (`BRANDS`). **Перед запуском сверьте их с партнерами.**
