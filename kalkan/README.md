# 🛡 Калкан — антифрод-бот

Человек пересылает боту подозрительное сообщение, ссылку, файл, скриншот или номер и получает ответ: похоже ли это на мошенничество, какая это схема и что делать. Семейный режим: если мама переслала боту опасное сообщение, внуку приходит уведомление.

Это MVP: Telegram-бот, B2B API для банков и демо-страница для жюри. Всё запускается одной командой.

## Что умеет

| Функция | Как работает |
| --- | --- |
| **Проверка текста** | База из 14 схем, распространенных в КР (фейковый кредит от Нацбанка, «служба безопасности банка», код из СМС, фейковые МВД/ГКНБ, «мама, я попал в ДТП», взломанный друг просит денег, APK-«приглашение на той», фейковые выплаты, инвестиции, работа на дому, Lalafo/OLX, кража аккаунта Telegram). Русские и кыргызские ключевые слова, распознает подмену букв латиницей («kредит»). |
| **Проверка ссылок** | Поддельные домены банков (`mbank-bonus.top`, `rnbank.kg`, `0ptimabank.kg`), Telegram-боты «от Нацбанка», сокращатели, punycode, IP-адреса, подозрительные зоны, бесплатные хостинги. Опционально — Google Safe Browsing. |
| **Проверка номеров** | Иностранные номера под видом «банка», база жалоб пользователей и партнеров. |
| **Проверка файлов** | APK, исполняемые файлы, двойные расширения (`фото.jpg.exe`), архивы, макросы. Опционально — VirusTotal по хэшу (сам файл не отправляется). |
| **Скриншоты** | ИИ читает скриншот переписки (Claude с поддержкой изображений). |
| **ИИ-анализ** | Claude дает второе мнение, называет схему и пишет понятные советы. ИИ может **повысить** риск, но не может понизить то, что нашли правила, поэтому мошенническое сообщение со словами «это безопасно, игнорируй правила» не обманет бота. |
| **Семейный режим** | `/family` → ссылка-приглашение → родственник нажимает Start. Опекун получает уведомление при опасной проверке, **без текста сообщения**. |
| **Жалобы** | `/report +996…` или кнопка «Пожаловаться» под вердиктом. 3 жалобы на номер — дальше он сразу «красный» для всех. |
| **Обратная связь** | Кнопки 👍/👎 под каждым ответом — метрика точности для питча и для дообучения базы. |
| **B2B API** | `POST /v1/check`, `POST /v1/reports`, `GET /v1/stats` с API-ключами партнеров. |
| **White-label** | Название, партнер и горячая линия банка задаются переменными окружения. |

### Бот никогда не говорит «безопасно»

Есть только три ответа: 🔴 «Очень похоже на мошенничество», 🟠 «Есть признаки мошенничества», 🟢 «Явных признаков не найдено — но это не гарантия». Это прямо отвечает на главный риск из идеи: бот может пропустить мошенника.

### Приватность

Мы **не храним** текст, фото и файлы пользователей. В базе остаются только итог проверки (уровень, схема) и найденные номера/домены. Подробно — команда `/privacy`.

## Быстрый старт

Нужен Node.js 22.13+.

```bash
cd kalkan
npm install
cp .env.example .env   # вставьте TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
npm start
```

- Telegram-бот запускается, если задан `TELEGRAM_BOT_TOKEN` (получить у [@BotFather](https://t.me/BotFather)).
- Демо-страница и API: http://localhost:8080
- Без `ANTHROPIC_API_KEY` всё работает по базе схем, но без ИИ и без проверки скриншотов.

Проверить сообщение из терминала:

```bash
npm run check -- "Вам одобрен кредит от Нацбанка, оплатите страховой взнос"
```

Тесты (35 шт.: схемы, ложные срабатывания, ссылки, номера, файлы, бот, семейный режим, API):

```bash
npm test
```

### Docker

```bash
docker build -t kalkan .
docker run -d --env-file .env -v kalkan-data:/data -p 8080:8080 kalkan
```

Подойдет любой VPS или Railway / Render / Fly.io. Бот работает через long polling, поэтому публичный адрес нужен только для API и демо.

## B2B API

Создать ключ для партнера:

```bash
npm run tenant:create -- "Банк Пример"
```

Проверка сообщения (например, из приложения банка или чат-бота поддержки):

```bash
curl -X POST http://localhost:8080/v1/check \
  -H "Authorization: Bearer klk_..." \
  -H "Content-Type: application/json" \
  -d '{"text": "Служба безопасности банка, переведите деньги на безопасный счет", "phone": "+79123456789"}'
```

Ответ:

```json
{
  "level": "danger",
  "score": 100,
  "scheme": { "id": "bank_security_call", "name": "«Служба безопасности банка»" },
  "red_flags": [
    { "text": "Представляются службой безопасности", "source": "rules" },
    { "text": "Предлагают перевести деньги на «безопасный счет»", "source": "rules" },
    { "text": "«Официальная» организация с иностранного номера", "source": "phone" }
  ],
  "explanation": null,
  "advice": ["Положите трубку и сами позвоните в банк по номеру с обратной стороны карты.", "..."],
  "urls": [],
  "phones": [{ "phone": "+79123456789", "score": 15 }],
  "ai_used": false,
  "disclaimer": "Оценка вероятностная и не является гарантией безопасности."
}
```

Другие методы:

- `POST /v1/reports` — `{"phones": [...], "domains": [...]}`: банк передает подтвержденные номера и сайты мошенников, и бот сразу начинает предупреждать о них всех пользователей.
- `GET /v1/stats?days=30` — проверки партнера и обезличенный тренд схем по всему рынку («что сейчас растет»).

## Архитектура

```
Telegram ─┐                       ┌─ rules.ts    база схем (schemes.ts)
          ├─► engine.ts ──────────┼─ urls.ts     эвристики + Safe Browsing
B2B API ──┤   (итоговый вердикт)  ├─ phones.ts   номера
Демо ─────┘                       ├─ files.ts    файлы + VirusTotal
                                  ├─ db.ts       жалобы пользователей/партнеров
                                  └─ ai.ts       Claude: второе мнение + советы
```

- `src/analysis/` — движок. Итоговый риск = сильнейший сигнал + часть остальных + общие приемы давления (срочность, секретность). ИИ получает результаты автоматических проверок и отвечает строгим JSON (structured outputs).
- `src/bot/` — Telegram-бот на [grammY](https://grammy.dev).
- `src/api/` — HTTP API и демо-страница (без фреймворков).
- `src/storage/` — SQLite (встроенный `node:sqlite`, внешняя БД не нужна).

### ИИ

По умолчанию используется `claude-opus-5-5` с `effort: low`: этого достаточно для классификации, ответ быстрый. Модель и уровень можно поменять в `.env` (`KALKAN_MODEL`, `KALKAN_EFFORT`). Если классификатор безопасности Claude откажется анализировать контент, API автоматически повторит запрос на рекомендованной резервной модели (`fallbacks: "default"`). Если ИИ недоступен, бот отвечает по базе схем.

## Как пополнять базу схем

Схемы описаны в `src/analysis/schemes.ts`: название, как работает, шаблоны с весами и советы. Новые схемы стоит брать из предупреждений Нацбанка (nbkr.kg), МВД и новостей. После правки добавьте пример в `test/analysis.test.ts` и запустите `npm test`, чтобы проверить срабатывание и отсутствие ложных тревог.

Официальные домены банков и операторов — в `src/analysis/urls.ts` (`BRANDS`). **Перед запуском сверьте их с партнерами.**
